Architecture & Concept

Why We Built RustStack: Zero-JVM, Zero-Python Cloud Emulation

Traditional AWS emulators bundle Python interpreters, JVM runtimes, Node.js processes, and gigabytes of dependencies inside a heavy container. RustStack rethinks local cloud emulation from first principles as a single, lock-free async Rust binary.

🔌 Single-Port AWS Protocol Multiplexer

Every AWS service uses slightly different wire conventions. RustStack inspects incoming HTTP headers, X-Amz-Target, query parameters, and hostnames on port 4566 to route requests in sub-microseconds:

  • REST-XML & Virtual-Host/Path Routing: Amazon S3, Route 53
  • AWS JSON 1.0 / 1.1: DynamoDB, KMS, EventBridge, SSM, Secrets Manager, Logs
  • AWS Query (form-urlencoded): STS, IAM, SQS, SNS, RDS, ElastiCache, EC2
  • REST-JSON: Lambda, API Gateway v1/v2, AppSync, Bedrock, Pipes

⚡ Cross-Service Reactive Event Bus

Cloud-native integration tests don't test services in isolation — they test event-driven pipelines. RustStack wires all 37 crates together in memory with zero network hops:

  • S3 Bucket Notifications: PutObject triggers instant delivery to SQS queues, SNS topics, and EventBridge buses.
  • SNS → SQS Fanout: FilterPolicy matching and raw message delivery across subscribed queues.
  • DynamoDB Streams CDC: Real-time INSERT / MODIFY / REMOVE shard capture.
  • EventBridge & Pipes: Content-based JSON rule matching routed directly to target services.

🧪 Built for Deterministic CI & Chaos Testing

Instead of restarting containers between tests, RustStack exposes an instant HTTP control plane on /_ruststack/* and an embedded dark-mode Web Admin UI:

  • Atomic State Reset (<1ms): Wipe all 37 services or selected services between test cases via POST /_ruststack/state/reset.
  • State Snapshots: Export and restore entire multi-service cluster state as JSON.
  • Chaos Fault Injection: Inject ProvisionedThroughputExceededException, 503 SlowDown, or latency jitter per service/action.

Drop-In Integration

Use RustStack in GitHub Actions, Docker, or Testcontainers

Point any AWS SDK (Python boto3, Go aws-sdk-go-v2, JS/TS @aws-sdk/*, Rust aws-sdk-*) or the AWS CLI at RustStack by setting AWS_ENDPOINT_URL=http://localhost:4566.

.github/workflows/integration.yml — Service Container 
jobs:
  integration-test:
    runs-on: ubuntu-latest
    services:
      ruststack:
        image: ehlers320/ruststack:latest
        ports:
          - 4566:4566
        options: >-
          --health-cmd "wget -qO- http://localhost:4566/_ruststack/health || exit 1"
          --health-interval 2s
          --health-timeout 2s
          --health-retries 5
    env:
      AWS_ENDPOINT_URL: http://localhost:4566
      AWS_ACCESS_KEY_ID: test
      AWS_SECRET_ACCESS_KEY: test
      AWS_DEFAULT_REGION: us-east-1
    steps:
      - uses: actions/checkout@v4
      - name: Run integration tests against local AWS emulator
        run: |
          aws s3 mb s3://my-ci-bucket
          pytest
.github/workflows/integration.yml — Zero-Docker Static musl Binary (~10ms start) 
jobs:
  integration-test:
    runs-on: ubuntu-latest
    env:
      AWS_ENDPOINT_URL: http://localhost:4566
      AWS_ACCESS_KEY_ID: test
      AWS_SECRET_ACCESS_KEY: test
      AWS_DEFAULT_REGION: us-east-1
    steps:
      - uses: actions/checkout@v4

      - name: Start RustStack static binary
        run: |
          curl -fsSL https://github.com/ehlerst/ruststack/releases/latest/download/ruststack-x86_64-unknown-linux-musl.tar.gz \
            | sudo tar xz -C /usr/local/bin
          ruststack start --port 4566 &
          for i in $(seq 1 20); do
            curl -sf http://localhost:4566/_ruststack/health && break
            sleep 0.1
          done

      - name: Run test suite
        run: cargo test

Frequently Asked Questions

Everything You Need to Know About RustStack

What is RustStack and how does it compare to LocalStack and Moto?

RustStack is a single-binary local AWS cloud emulator written in 100% pure Rust. Unlike LocalStack (which requires a heavy Python/JVM container using ~398.5 MiB idle memory and ~2.77s startup) or Moto (Python-based), RustStack starts in ~230ms, consumes 2.2 MiB of idle RAM (177x lighter), and ships as a 38 MB Docker image or standalone static binary.

How do I point my AWS SDK or Terraform at RustStack?

Set the standard environment variable AWS_ENDPOINT_URL=http://localhost:4566 along with dummy credentials (AWS_ACCESS_KEY_ID=test, AWS_SECRET_ACCESS_KEY=test, AWS_DEFAULT_REGION=us-east-1). All modern AWS SDKs (Python boto3, Go aws-sdk-go-v2, Node.js @aws-sdk/*, Rust aws-sdk-*, and the AWS CLI v2) natively honor AWS_ENDPOINT_URL.

Is RustStack an S3 client or file sync CLI tool?

No. RustStack is an AWS server/cloud emulator for local development and integration tests (like LocalStack or Moto) — not an S3 transfer/sync CLI client like s5cmd or rclone.

Does RustStack persist data across restarts or support resetting state between tests?

Yes! By default, RustStack runs purely in memory for maximum speed and lets you reset state between tests in under 1 millisecond via POST http://localhost:4566/_ruststack/state/reset. If you want persistence across restarts, pass --data-dir ./data or set RUSTSTACK_DATA_DIR=/data to automatically load and save state snapshots.
